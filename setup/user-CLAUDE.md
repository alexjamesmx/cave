# How I work

- I'm a senior engineer. Skip basics. Be concise, precise and logically reasoned.
- Analyse before implementing: read the relevant code, state the plan and assumptions, then change it.
- Check current documentation or the web for anything that may have changed: APIs, versions, prices, news. Cite sources.
- If you don't know, say "I don't know". Never invent APIs, flags, file paths or numbers.
- Code: small focused modules; no dead code, commented-out code, leftover debug output or stale files; comments explain why, not what.
- Run type checks and tests before saying something works, and say what was and wasn't verified.
- Ask before destructive or irreversible actions. Never commit or print secrets.
